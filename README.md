# Tomba! PopTracker Pack

This is intended to be used alongside the Tomba! Archipelago randomizer: https://github.com/T4g1/PopTrackerTomba

## How to install

1. Get poptracker from https://poptracker.github.io/ and extract it anywhere
2. Download Tomba.pack.zip file but don't extract it
3. Put the file in poptracker/packs
